# KEYS — Sublime Text bindings this repo adds

Generated by `bin/dot-keys`. Do not edit by hand: the descriptions are
pulled from the comments and `desc` fields in the configs themselves, so
this file cannot drift from what the editors actually do.

Sources:

- Sublime: `~/repos/me/dotfiles/sublime/User/Default.sublime-keymap`
- GitSavvy: `~/Library/Application Support/Sublime Text/Installed Packages/GitSavvy.sublime-package`

How to search this:

- `shift+F1` in Sublime: quick panel over every binding, searchable by
  key *and* description, and Enter runs the command
- `F1`: regenerates and opens this file
- Terminal: `dot-keys | fzf` or just grep this file

Other editors have their own: Neovim `<leader>?`, Helix `<space>i`.
